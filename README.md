# Monkey AIsland

**A Generative AI Capability Benchmark by [Jamie Skella](https://www.linkedin.com/in/jamieskella/), framed through the technical legacy of *The Secret of Monkey Island* (1990).**

This repository hosts the project's website. The current paper, methodology, evaluation scorecard, and each generation's playable build all live at the canonical site:

### → [monkeyaisland.com](https://monkeyaisland.com)

The site is updated alongside each new generation of the benchmark. For machine-readable summaries, see [llms.txt](https://monkeyaisland.com/llms.txt) and [llms-full.txt](https://monkeyaisland.com/llms-full.txt).
